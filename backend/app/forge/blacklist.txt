# 审核正则快筛黑名单：每行一条规则，命中即决（不调审核 LLM）。
# 对【原文】匹配（保留空格/词界），与 AC 词库分工如下：
#
#   本文件 blacklist.txt     → 越狱/提示注入、恶意代码正则，及运营临时自定义规则
#   app/forge/lexicons/      → 赌毒/色情/暴恐等中文内容词（block 即决）与政治灰名单
#
# 不要把大批量中文敏感词写进本文件：字面子串无归一化/白名单，短词极易误伤游戏文本；
# 内容词请改 lexicons/block|suspect/*.txt（见 docs/sensitive-lexicon-detection.md）。
#
# 行格式（# 开头为注释，空行忽略）：
#   敏感词                  → 字面子串匹配（自动转义，写普通词即可）
#   re:正则                 → 正则匹配（大小写不敏感；正则里的 | 是或运算，不识别分类）
#   分类|敏感词             → 指定命中分类，分类须为纯小写字母/下划线
#                            （默认 sensitive_word；可用 jailbreak/harmful_code 等自定义值）
#
# 文件按 mtime 热加载：改完保存即生效，无需重启服务。
# 注意：普通词是子串匹配，加过短的词（如"杀"）会大量误伤正常游戏文本。

# ---- 越狱/提示注入 ----
re:ignore\s+(?:all\s+)?(?:previous|prior|above|system|developer|earlier)\s+(?:instructions?|prompts?|rules?)
re:disregard\s+(?:all\s+)?(?:previous|prior|above)
re:\bDAN\b|\bjailbreak\b|越狱|绕过(?:限制|审核|安全|护栏)|忽略(?:所有|之前|全部)?(?:指令|规则|限制|提示)

# ---- 恶意代码 ----
re:<script[^>]*>\s*eval\s*\(
re:javascript:[^;\s]
re:onerror\s*=\s*["']
re:new\s+WebSocket\s*\(|navigator\.sendBeacon\s*\(
