01 是什么

从一句玩法描述，走到一个可以打开的网页游戏。

GameForge 是面向浏览器游戏的 AI 辅助创作工作区。它把创作过程组织为可审阅的策划、可追踪的生成任务和可直接打开的游戏版本。

本页仅展示当前主分支已有能力。下方视频中的两个作品是已发布、可实际操作的官方 Demo；规划功能会单独标记，不与现有能力混写。

WORKFLOW

从描述到试玩的六步链路

每一步都对应当前产品的实际工作流。

  1. 01

    描述想法

    在 Forge 工作区用自然语言说明玩法、角色和规则。

    已实现
  2. 02

    AI 策划

    生成可查看的设计方案，将创作意图整理为游戏设计。

    已实现
  3. 03

    人工确认

    确认方案后，才进入后续生成流程。

    已实现
  4. 04

    生成游戏

    Worker 执行生成、校验与阶段进度处理。

    已实现
  5. 05

    浏览器试玩

    草稿或已发布版本均可在浏览器中直接打开。

    已实现
  6. 06

    下载或发布

    下载自己的独立 HTML 版本，或提交进入发布审核流程。

    已实现

BUILT INTO THE PRODUCT

已实现的创作与交付能力

A

自然语言创作

在一个工作区内描述想法、查看消息与跟踪生成阶段。

B

策划先行

先审阅 AI 策划，再决定是否继续生成，保留人为确认环节。

C

浏览器内试玩

游戏版本在产品内的隔离页面中打开，不需要额外安装客户端。

D

版本与发布管理

管理游戏草稿和版本，下载本人版本，提交并处理发布审核流程。
